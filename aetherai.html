ABOUT THIS DEMONSTRATION

The original project uses normalized all-mpnet-base-v2 vectors with FAISS inner product (cosine similarity) and applies a +0.10 boost when the full query appears in a retrieved chunk. Its default Top-K is 5. This interface uses fixed Top-5 and a curated concept map to illustrate semantic matching; no model, vector index or backend runs here. Keyword coverage is shown for context, and AetherAI returns documents rather than generated answers. View the source project ↗
