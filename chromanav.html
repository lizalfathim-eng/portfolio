COMPUTER VISION   /   ACCESSIBILITY

ChromaNav

A real-time computer vision application designed to detect traffic signals and assist colour-blind drivers through visual recognition.

Traffic lights communicate through colour. ChromaNav explores an additional way to recognise a detected signal and announce its estimated colour, so users do not have to rely on colour alone.

03   HOW IT WORKS

From camera frame
to spoken cue.

Open each step for a little more detail. The flow describes the Python application—not an in-browser demo.

01 INPUTWebcam frame

Starting detection opens the default webcam through OpenCV and reads frames from camera device 0.

02 OBJECT DETECTIONYOLOv8

The Ultralytics YOLO model looks for supported objects. The app maps only traffic lights and stop signs, using a 0.50 confidence threshold.

03 TRAFFIC LIGHT ONLYHSV colour estimate

For a detected traffic light, OpenCV checks HSV colour masks within the cropped box and uses the expected top-to-bottom signal positions as a heuristic. If it is unsure, the label stays “Traffic Light.”

04 FEEDBACKOverlay + speech

OpenCV draws a box and label in its video window. A separate pyttsx3 worker speaks queued labels, including estimated light colours or “Stop.”

COLOUR IS ESTIMATED FROM PIXELS — IT IS NOT A SEPARATE YOLO CLASS. OTHER DETECTION CLASSES ARE IGNORED.

04   TECHNICAL OVERVIEW

A small desktop
computer vision system.

The project brings together a webcam loop, a pretrained object detector, a colour heuristic, and queued speech output.

IMPLEMENTATION NOTES

Mapped classesTraffic light · stop sign
Colour methodHSV masks + vertical-position heuristic
Inference input640 px · at most 8 inferences / sec
Default weightsyolov8n.pt · required locally

This is a prototype with deliberately narrow class coverage. Colour estimates can be uncertain when lights are small, obscured, unusually arranged, or seen in poor lighting; false positives and missed detections remain possible.

!

ChromaNav is an assistive prototype, not a certified road-safety system. It should not replace visual awareness or independent road-safety decisions.
