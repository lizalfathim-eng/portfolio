MACHINE LEARNING INTERNSHIP PROJECT

User Profiling & Segmentation for Targeted Advertising

Exploring user characteristics and online engagement to understand how audience groups can inform more relevant digital advertising.

Remarkskill Education × FCC, IIT Hyderabad · August–September 2025

Back to selected projects ↗

PROJECT OVERVIEW

Finding meaningful audience groups.

This individual project explored machine-learning approaches to user segmentation using 1,000 user profiles across 16 demographic and behavioural features. The aim was to understand patterns in user characteristics and online engagement, and how audience profiling could inform targeted campaign strategies.

PROJECT FOCUS

From user data to audience insight.

  • Analysing demographic and behavioural user data.
  • Exploring patterns in engagement and advertising interactions.
  • Investigating how segmentation can support audience profiling and targeted campaign strategies.

SCOPE & ROLE

A six-week individual project.

Dataset: 1,000 user profiles across 16 demographic and behavioural features.

Role: Individual project contributor.

Duration: 6 weeks, August–September 2025.

Programme: Machine Learning Internship Project · Remarkskill Education × FCC, IIT Hyderabad.
